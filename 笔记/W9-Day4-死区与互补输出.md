# W9 Day4 —— 死区与互补输出（TIM1）

> 目标：理解 H 桥为什么需要死区，用 TIM1 的互补输出 + 硬件死区生成器实现，
> 并用逻辑分析仪实测死区时间，验证公式。

---

## 一、为什么需要死区

### 1.1 H 桥结构

```
        VCC (12V / 24V)
         │
    ┌────┴────┐
    │Q1      Q3│
    ├─┤      ├─┤
    │         │
    A ──────── B   ← 电机
    │         │
    ├─┤      ├─┤
    │Q2      Q4│
    └────┬────┘
         │
        GND
```

| 转向 | 导通 | 关断 |
|---|---|---|
| 正转 | Q1、Q4 | Q2、Q3 |
| 反转 | Q2、Q3 | Q1、Q4 |

### 1.2 直通（shoot-through）

换向瞬间：

```
理想：Q1 关断 → Q2 导通（瞬间完成）
实际：Q1 关断需要几百 ns ~ 几 μs
     如果 Q2 立刻导通 → Q1 和 Q2 【同时导通】
     → VCC 直接短路到 GND
     → 电流几十~几百安培 → 【MOSFET 烧毁】
```

**这是电机驱动最经典的烧板方式。**

### 1.3 死区的定义

```
无死区（危险）：           有死区（安全）：
Q1: ‾‾‾‾|________        Q1: ‾‾‾‾|____|________
              ↑↑                    ↑   ↑
Q2: ______|‾‾‾‾‾‾‾        Q2: _____|____|‾‾‾‾‾‾‾
        同时导通                  死区（两边都关断）
```

**死区 = 换向时两个开关都保持关断的空档时间。**

**TIM1 的硬件死区生成器**：配一个 DTG 值，硬件自动插入，**软件不用算延时**。

## 二、TIM1 与 TIM2 的 5 个区别

| # | 项 | TIM2（通用定时器） | **TIM1（高级定时器）** |
|---|---|---|---|
| **1** | 所在总线 | APB1（36MHz，**自动 ×2** = 72MHz） | **APB2（72MHz，直接用）** |
| **2** | 输出引脚 | CH1 一个（PA0） | **CH1（PA8）+ CH1N（PB13）两个** |
| **3** | `CCER` 使能位 | 只开 `CC1E`（bit0） | **`CC1E`（bit0）+ `CC1NE`（bit2）** |
| **4** | **`BDTR` 寄存器** | ❌ 没有 | ✅ **有（死区 + MOE）** |
| **5** | 时钟使能位 | `APB1ENR` bit0 | `APB2ENR` **bit11** |

**⚠️ 第 3、4 条是最容易漏的** —— 漏了任何一个，引脚都完全没有输出。

---

## 三、互补输出引脚

| 通道 | 主输出 | 互补输出 |
|---|---|---|
| **CH1 / CH1N** | **PA8** | **PB13** |
| CH2 / CH2N | PA9 | PB14 |
| CH3 / CH3N | PA10 | PB15 |

**⚠️ 两个引脚都要配成复用推挽（`GPIO_CFG_AF_PP_50MHZ`），而且 GPIOB 的时钟要单独开。**

---

## 四、`BDTR` 寄存器（TIM1 独有）

| 位 | 名称 | 作用 |
|---|---|---|
| **[7:0]** | **DTG** | **死区时间生成器（Dead-Time Generator）** |
| [9:8] | LOCK | 锁定 BDTR 配置，防止误改 |
| [11:10] | OSSI / OSSR | 空闲状态时的输出配置 |
| [12:13] | BKE / BKP | 刹车功能（过流保护）+ 极性 |
| [14] | AOE | 自动输出使能 |
| **[15]** | **MOE** | **主输出使能（Main Output Enable）** |

**⚠️ `MOE = 0` 时，前面所有配置都对，两个引脚也一点输出都没有** —— 这是最隐蔽的坑。

**一条语句配好**：

```c
TIM1->BDTR = (1UL << 15) | 72;      /* MOE + 死区 1μs */
```

## 五、死区时间公式

### 5.1 基础时间

```
t_DTS = 1 / 72MHz = 13.89 ns
```

### 5.2 公式（DTG[7:5] = 0xx，最常用的一段）

```
死区时间 = DTG[7:0] × t_DTS = DTG × 13.89 ns

反解： DTG = 目标死区(ns) / 13.89
```

**⚠️ 这一段只覆盖 `DTG ≤ 127`（约 1.76 μs）**。更大的死区要换编码段：

| `DTG[7:5]` | 死区时间 |
|---|---|
| **`0xx`**（0~127） | `DTG[7:0] × t_DTS` |
| `10x` | `(64 + DTG[5:0]) × 2 × t_DTS` |
| `110` | `(32 + DTG[4:0]) × 8 × t_DTS` |
| `111` | `(32 + DTG[4:0]) × 16 × t_DTS` |

**DTG 编码是分段的、非线性的** —— 不能简单当成"乘 t_DTS"。

### 5.3 常用对照

| 目标死区 | `DTG` | 实际 |
|---|---|---|
| 100 ns | 7 | 97 ns |
| 200 ns | 14 | 194 ns |
| **500 ns** | **36** | **500 ns** |
| **1000 ns** | **72** | **1000 ns** |
| 1500 ns | 108 | 1500 ns |
| 1700 ns | 122 | 1694 ns |

## 六、配置流程

```
① 时钟：RCC->APB2ENR |= IOPAEN | IOPBEN | TIM1EN（bit11）
② 两个引脚都配复用推挽：PA8（CH1）、PB13（CH1N）
③ 时基：TIMER_Setup(TIM1, 1, 1000) → 1μs/计数、1kHz
④ CH1 模式：CCMR1 = OC1PE(bit3) | OC1M=110(bits[6:4])
⑤ 占空比：CCR1 = 500（50%）
⑥ CCER 使能【两位】：CC1E(bit0) + CC1NE(bit2)
⑦ BDTR：DTG + MOE(bit15)
⑧ ★ 最后启动：CR1 = ARPE(bit7) | CEN(bit0)
```

**⚠️ `CEN` 必须最后置 1** —— 所有配置就绪后再启动，否则会有一瞬间的异常波形。

## 七、实测数据

### 7.1 死区时间（三组，验证公式）

| `DTG` | 理论值 | 实测 | 偏差 |
|---|---|---|---|
| **36** | 500.0 ns | **500 ns** | 0 |
| **72** | 1000.0 ns | **974 ns** | −26 ns |
| **122** | 1694.4 ns | **1686 ns** | −8 ns |

**线性度校验**：

```
DTG 36 → 122（跨 86 个计数）
实测差值 = 1686 − 500 = 1186 ns
每个计数 = 1186 / 86 = 13.79 ns

理论 = 1 / 72MHz = 13.89 ns
误差 = 0.7%  ✅
```

**三个点在一条直线上，斜率与理论吻合 → 公式 `DTG = ns / 13.89` 成立。**

### 7.2 对称性（两个方向都要有死区）

| 方向 | 理论 | 实测 |
|---|---|---|
| CH1 关断 → CH1N 导通 | 1000 ns | **974 ns** |
| CH1N 关断 → CH1 导通 | 1000 ns | **998 ns** |

**两个方向都有 ≈1μs 的间隙 → 死区生成器工作正常。**

**⚠️ 为什么必须验证两个方向**：如果只有一个方向有死区，H 桥在另一个方向换向时仍会直通。

### 7.3 周期与占空比

| 量 | 理论（ARR=999, CCR1=500, DT=1μs） | 实测 |
|---|---|---|
| **周期** | 1000 μs | **1001 μs** ✅ |
| **D0（CH1）高** | **499 μs**（500 − 1） | 497 μs |
| **D0（CH1）低** | **501 μs**（500 + 1） | 504 μs |
| **D1（CH1N）高** | **499 μs**（500 − 1） | 499 μs ✅ |

**⭐ 关键认识：两个通道的高电平都【不到 500μs】** —— 因为死区从每边各"吃掉" 1μs。

**这就是死区对电机的实际影响：有效电压略低于理论值。**

## 八、⚠️ 测量精度的教训

### 8.1 "精度 1ns" 是假的

| 项 | 值 |
|---|---|
| 采样率 | 24 MHz |
| **采样间隔** | **41.7 ns** |
| **真实可分辨精度** | **±42 ns** |

**PulseView 光标读数会显示到小数点后好几位，那是"虚假精度"（false precision）** —— 显示位数超过了仪器实际分辨率。

**正确表述**：

> ❌ "逻辑分析仪测的，精度 1ns"
> ✅ **"24MHz 采样，分辨率 41.7ns，1μs 的死区实测 974ns，和理论 1000ns 的差在 ±42ns 内"**

### 8.2 不同量级要用不同缩放

| 要测的量 | 需要的窗口 | 该视图的精度 |
|---|---|---|
| **死区（1μs）** | ~2 μs | **±42 ns** ✅ |
| 周期（1ms） | ~2 ms | ±1.5 μs |

**在 1300 像素宽的窗口里看 2ms，1 像素 = 1.54 μs** —— 光标放偏 1~2 像素就有 2~3μs 误差。

**所以 7.3 表里 D0 高 497 vs 理论 499 的差，是光标误差而不是硬件问题。**

**⭐ 教训：不能拿"测周期的视图"去测死区，也不能拿"测死区的视图"去测周期。**

## 九、踩坑记录

### 坑 1：`CR1` 误写成 `(1UL<<0) | 72UL` → 波形完全出不来

**`72` 的二进制是 `0b01001000`**，不是"向右移 7 位"：

| 位 | 值 | 名称 | 后果 |
|---|---|---|---|
| 0 | 1 | CEN | 想要这个 |
| **3** | **1** | **OPM** | **单脉冲模式 → 只输出一个周期就停** |
| **6** | **1** | **CMS[1]** | **中心对齐模式 → 频率减半** |

**现象**：PA8 上只有一个 1ms 的脉冲然后永久停止 → **逻辑分析仪抓不到连续波形**。

**正确写法**：

```c
TIM1->CR1 = (1UL << 7) | (1UL << 0);    /* ARPE + CEN，不是 72 */
```

**⚠️ `1<<7 = 128`，`72` 是十进制数** —— 这两个完全不同。

### 坑 2：忘 `BDTR` 的 `MOE`

**现象**：所有配置都对，两个引脚**一点输出都没有**。

**原因**：TIM1 是"高级定时器"，有刹车（break）机制，**必须显式使能主输出（MOE）**才会往外送信号。

## 十、死区对电机的实际影响

| 死区大小 | 影响 |
|---|---|
| **0** | **H 桥直通 → 烧管子** |
| **太小**（< MOSFET 关断时间） | 仍有直通风险 |
| **合适**（略大于关断时间） | 安全，效率损失小 |
| **太大**（如 10μs） | **有效电压明显下降**；高速时丢力矩；低速时转矩脉动 |

**为什么大死区会丢力矩**：死区期间两个管子都关断，电机电流通过续流二极管走，**实际加到电机上的电压比 PWM 占空比算出来的低**。

**工程取值**：一般为 MOSFET 关断时间 + 余量，常见 **0.5~2 μs**。

## 十一、思考题与答案

| # | 问题 | 答案 |
|---|---|---|
| **1** | 只配 PA8 不配 PB13 会怎样？ | PB13 保持浮空输入，**CH1N 完全没有输出** → 死区无法验证 |
| **2** | `MOE` 不置 1 会怎样？ | **两个引脚都完全没输出**。ST 设计它是为了**紧急刹车**：过流时硬件清 MOE，所有输出立即进入空闲安全状态 |
| **3** | 死区能为 0 吗？ | 能，但那等于**放弃硬件保护**。只有用**外部已含死区的驱动芯片**（如 IR2110 内部的）或**低压小功率场合**才可省略 |
| **4** | 死区太大会怎样？ | 有效电压下降、高速丢力矩、低速转矩脉动加大 |
| **5** | `TIMER_PwmStart` 能直接驱动 TIM1 的 CH1 吗？ | **不能** —— 它不写 `CC1NE`、不写 `BDTR`（无 MOE），TIM1 会完全无输出 |

## 十二、结论

1. **H 桥换向必须留死区**，否则直通烧管子；TIM1 硬件自动插入，不用软件延时。
2. **TIM1 比 TIM2 多 2 个必配项**：`CCER` 的 `CC1NE`、`BDTR` 的 `MOE`。
3. **死区公式**：`DTG = 目标(ns) / 13.89`（DTG ≤ 127 的分段），实测线性度误差 0.7%。
4. **两个换向方向都要验证死区**，只验一边不够。
5. **死区会让每路高电平变短**（各 −1μs），这是有效电压下降的直接原因。
6. **测量要匹配量级**：ns 级用放大视图，ms 级用缩小视图；**报精度必须报仪器真实分辨率（41.7ns），不是软件显示的小数位**。
