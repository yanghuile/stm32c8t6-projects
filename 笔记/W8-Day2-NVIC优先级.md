## 一、时序图
1. 情况一：抢占（高抢占级打断低抢占级）
时间轴 ──────────────────────────────────────────────────►

中断 B（抢占 2）  ████        ██████████████
（正在执行）          ↑ 被打断     ↑ 恢复执行
                      │           │
中断 A（抢占 1）  ────████████────┘
（更高，到来）        （执行完）

结论：A 抢占 B，A 执行完后 B 从中断点继续

2. 情况二：不抢占（抢占级相同，只有响应级不同）
时间轴 ──────────────────────────────────────────────────►

中断 C（抢占2,响应0） ████████████████
中断 D（抢占2,响应1）      ───────────────████████
                            （排队等待）

结论：D 不能打断 C；C 执行完 D 才开始
      ★ 响应优先级只在【同时到达】时决定谁先

3. 同时到达
中断 C（抢占2,响应0） ┐
                      ├─ 同时到来 → C 先（响应级小）
中断 D（抢占2,响应1） ┘

中断 E（抢占1,响应3） ┐
                      ├─ 同时到来 → E 先（抢占级小，比响应级优先）
中断 C（抢占2,响应0） ┘

## 二、中断发生时，CPU 怎么知道该跳到哪个函数？ 那个"表"在哪、由谁定义？ 
1. CPU 拿到中断向量号，用这个编号去查中断向量表，表里存的是中断服务函数的入口地址，CPU 直接跳过去。
2. 向量表本质是一张存放函数指针的数组；
3. STM32F1 默认放在 Flash 起始地址 0x08000000；
4. 由启动文件（startup_stm32f10x.s）定义。

## 三、STM32F103 有几个优先级等级？为什么是 16 个？
16个。
Cortex‑M3 的 NVIC 优先级寄存器 IPR 每个中断是 8bit，但 STM32F103 只实现了高 4 位，2^4=16。这 4 位可以切分：抢占优先级 + 响应优先级，由 AIRCR 的 PRIGROUP 分组（5 种分组）：
- 组 0：0 抢占 + 4 响应优先级
- 组 1：1 抢占 + 3 响应优先级
- 组 2：2 抢占 + 2 响应优先级
- 组 3：3 抢占 + 1 响应优先级
- 组 4：4 抢占 + 0 响应优先级

## 四、数字越小优先级越高还是越低？ 举一个用错会出问题的场景。
数字越小优先级越高。
场景：串口中断、按键外部中断
配置：- 串口中断：抢占优先级 `2`
     - 外部中断（按键）：抢占优先级 `0`
本意：想让串口更紧急，优先响应串口。配反了，把串口写成 2，按键写成 0：按键优先级更高，按键中断可以随时打断串口接收。如果串口正在接收一串连续数据，按键一按下触发中断，串口被打断，很容易丢字节、串口数据错乱。

## 五、抢占优先级和响应优先级有什么区别？ 各在什么情况下起作用？
1. 抢占优先级：决定能不能打断别人（中断嵌套）；抢占优先级更小，可以打断正在运行的低抢占中断。
2. 响应优先级：不能嵌套；只有多个中断同时到来、抢占优先级一样的时候，响应优先级更小的先执行。

## 六、优先级分组 Group 2（2 位抢占 + 2 位响应）：中断 A 设 0x03，中断 B 设 0x04。A 正在执行时 B 到来，会怎样？ 如果 A 设 0x01、B 设 0x04 呢？如果 A 设 0x04、B 设 0x03 呢？如果 A 设 0x01、B 设 0x02 呢？

第一组：A=0x03，B=0x04
- A：0x03 → 二进制 `0011`
抢占 = `00`（0），响应 = `11`（3）
- B：0x04 → 二进制 `0100`
抢占 = `01`（1），响应 = `00`（0）

判断：A 抢占优先级 0 ＜ B 抢占优先级 1
 B 不能打断 A，B 排队，等 A 执行完再跑。
---
第二组：A=0x01，B=0x04
- A：0x01 → 二进制 `0001`
抢占 = `00`（0），响应 = `01`（1）
- B：0x04 → 二进制 `0100`
抢占 = `01`（1），响应 = `00`（0）

判断：A 抢占优先级 0 ＜ B 抢占优先级 1
还是 B 抢占优先级更低，依然不能打断 A，B 等待。
---
第三组：A=0x04，B=0x03
- A：0x04 → 二进制 `0100`
抢占 = `01`（1），响应 = `00`（0）
- B：0x03 → 二进制 `0011`
抢占 = `00`（0），响应 = `11`（3）

判断：A 抢占优先级 1 > B 抢占优先级 0
 B 抢占优先级更高，会打断A，转而执行B，等到B执行完，继续执行A。
---
第四组：A=0x01，B=0x02
- A：0x01 → 二进制 `0001`
抢占 = `00`（0），响应 = `01`（1）
- B：0x02 → 二进制 `0010`
抢占 = `00`（0），响应 = `10`（2）

判断：A 抢占优先级 0 = B 抢占优先级 0
 A 响应优先级更高，B 排队，等 A 执行完再跑。
如果A B抢占和响应优先级都相同并同时到来，比中断向量表里的序号，序号小的先执行
