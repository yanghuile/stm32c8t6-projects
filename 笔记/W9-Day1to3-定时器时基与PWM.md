# W9 Day1~3 —— 定时器时基 + 定时中断 + PWM 呼吸灯

> 目标：搞清定时器的时基计算，用寄存器配出定时中断和 PWM 输出，并做出一个呼吸灯。

---

## 一、定时器的本质

**一个会自己数数的计数器**：

```
时钟源（72MHz） → 预分频器 PSC → 计数器 CNT → 和 ARR 比较 → 溢出/更新
                                    ↑
                              数到 ARR 就归零，重新数
```

| 寄存器 | 作用 | 类比 |
|---|---|---|
| **PSC**（Prescaler） | 把 72MHz 降下来 | 分频器 |
| **CNT**（Counter） | 当前数到几 | 秒表读数 |
| **ARR**（Auto-Reload） | 数到多少归零 | 闹钟 |

---

## 二、⭐ 时基公式（最重要的一条）

```
f_out = f_clk / ((PSC + 1) × (ARR + 1))
```

**为什么都 +1**：PSC 和 ARR 都从 0 开始数。
**PSC = 0 → 不分频（÷1）；PSC = 71 → ÷72。**

### 2.1 定时器时钟是多少？

| 总线 | 挂的外设 | APB 频率 | **定时器时钟** |
|---|---|---|---|
| **APB1** | TIM2 / TIM3 / TIM4 | 36 MHz | **×2 = 72 MHz** |
| **APB2** | TIM1 | 72 MHz | 72 MHz |

**为什么 APB1 是 36MHz 但定时器是 72MHz**：
APB1 的分频系数为 2（≠1）时，硬件自动把定时器时钟 ×2，**等于 HCLK**。

**所以 TIM2 的 `f_clk = 72 MHz`，直接用，不用手动乘。**

### 2.2 三组常用配置

| 目标频率 | PSC 写 | ARR 写 | 校验 |
|---|---|---|---|
| **1 Hz**（1 秒） | 7199 | 9999 | 72M / 7200 / 10000 = 1 Hz |
| **10 Hz**（100 毫秒） | 7199 | 999 | 72M / 7200 / 1000 = 10 Hz |
| **1 kHz**（1 毫秒） | 71 | 999 | 72M / 72 / 1000 = 1 kHz |
| **10 kHz**（本项目 PWM） | **71** | **99** | 72M / 72 / 100 = **10 kHz** |

**⚠️ 最容易错的**：**忘了减 1**。写的是 `PSC = 71`，实际分频是 72。

## 三、配置 TIM2 定时中断（Day 2 实测通过）

```c
#include "stm32f103.h"
#include "led.h"

int main(void)
{
    LED_Init();                                  /* ★ 1. 先初始化 LED */

    /* 2. 开 TIM2 时钟（在 APB1！）*/
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;          /* LED 的 GPIO 在 APB2 */
    RCC->APB1ENR |= RCC_APB2ENR_TIM2EN;          /* TIM2 在 APB1 */

    /* 3. 时基 1 Hz */
    TIM2->PSC = 7199;        /* 72MHz / 7200   = 10 kHz */
    TIM2->ARR = 9999;        /* 10kHz / 10000  = 1 Hz  */
    TIM2->CNT = 0;

    /* 4. 产生一次更新事件，把 PSC/ARR 载入影子寄存器 */
    TIM2->EGR = 1;           /* UG = bit0 */

    /* 5. ★ 清 UIF（UG 会顺带置位它）*/
    TIM2->SR = (uint16_t)~1;

    /* 6. 允许更新中断 */
    TIM2->DIER |= 1;         /* UIE = bit0 */

    /* 7. 启动 */
    TIM2->CR1 |= 1;          /* CEN = bit0 */

    /* 8. NVIC */
    NVIC_IPR[IRQ_TIM2] = (uint8_t)(3 << 4);
    NVIC_ISER0  = (1UL << IRQ_TIM2);             /* IRQ 28 < 32 → ISER0 */

    while (1) { }
}

void TIM2_IRQHandler(void)
{
    if (TIM2->SR & 1)                              /* UIF 置位了吗 */
    {
        TIM2->SR = (uint16_t)~1;                   /* ★ 写 0 清除 */
        LED_Toggle();
    }
}
```

### 3.1 第 4 步 `EGR = 1` 到底做什么

**它叫"产生更新事件（Update Generation）"**，作用是**把 PSC / ARR / CCR 的值从"预装载寄存器"搬进"影子寄存器"**。

**为什么需要影子寄存器**：

```
你在数数的过程中改了 ARR，如果立即生效：
    CNT 正在数 5000，你把 ARR 从 9999 改成 3000
    → CNT > ARR，计数器行为未定义 → 可能一直数到 65535 才归零

有影子寄存器：
    你的写入先存在"预装载寄存器"
    → 等到本次计数周期结束（更新事件）才一起换上去
    → 一个周期内的计数过程不被打断
```

**所以 `EGR = 1` 是手动触发一次"更新事件"，让新配置立刻生效。**

**⚠️ 副作用**：`UG` 会**同时把 `UIF` 置 1**，所以必须紧接着清 `SR`，否则一开中断就立刻进一次 ISR（LED 会提前闪一下）。

---

## 四、⭐ 清标志的两种方式（重要）

| 寄存器 | 类型 | 正确写法 | 错误写法 |
|---|---|---|---|
| **`EXTI->PR`** | **W1C**（写 1 清） | `PR = mask` | ~~`PR \|= mask`~~ |
| **`TIM->SR`** | **W0C**（写 0 清） | `SR = ~mask` | ~~`SR &= ~mask`~~ |
| `NVIC_ISER` | 写 1 置位 | `ISER = mask` | ~~`ISER \|= mask`~~ |

### 为什么 `TIM2->SR &= ~1` 有风险

```c
TIM2->SR &= ~1;
/* 编译成三条指令：              */
/* LDR  r0, [SR]      ← 读到 0x0001 */
/* BIC  r0, r0, #1    ← 清 bit0 → 0x0000 */
/* STR  r0, [SR]      ← 写回 0x0000 */
```

**竞态时序**：

```
t0：LDR 读到 SR = 0x0001（只有 UIF）
t1：【CC1IF 被硬件置 1】→ SR 实际变成 0x0003
t2：STR 写回 0x0000 → 【把 CC1IF 也清掉了】→ 丢失一次捕获中断
```

**正确的 `TIM2->SR = (uint16_t)~1`**：

| 写入值 | 硬件行为 |
|---|---|
| `bit0 = 0` | **清除** UIF |
| 其他 `bit = 1` | **无影响**（W0C 写 1 不改变标志） |

**一条 `STR` 指令完成，没有读-改-写窗口。**

**这也是 SPL 的写法**：`TIM_ClearFlag()` 内部就是 `TIMx->SR = (uint16_t)~TIM_FLAG;`

**统一原则：清标志永远用"直接赋值"，不用 `|=` 或 `&=`。**

## 五、PWM 输出（Day 3 实测通过）

### 5.1 原理：CNT 和 CCR 比大小

```
CNT 从 0 数到 ARR（0→99），循环
                ↓
CNT <  CCR1  → 输出【高电平】
CNT >= CCR1  → 输出【低电平】
```

**ARR=99、CCR1=30（30% 占空比）**：

```
CNT:  0 ...... 30 .............. 99 → 0
      |←30% →|←───── 70% ──────→|

PWM:  ‾‾‾‾‾‾‾‾________________‾‾‾
      ↑ 一个周期
```

### 5.2 两个公式

| 量 | 公式 | 本项目（PSC=71, ARR=99, CCR=50） |
|---|---|---|
| **PWM 频率** | `72MHz / ((PSC+1)(ARR+1))` | 72M / 72 / 100 = **10 kHz** |
| **占空比** | `CCR1 / (ARR+1)` | 50 / 100 = **50%** |

**0% 和 100% 也能做到**：

| CCR1 | 占空比 | 原因 |
|---|---|---|
| **0** | **0%** | `CNT < 0` 永不成立 → 一直低 |
| `ARR+1`（=100） | **100%** | `CNT < 100` 永远成立 → 一直高 |

**⚠️ 常见误解**：以为 PWM 模式 1 做不到 100%。**`CCR = ARR + 1` 就能做到。**

### 5.3 ⭐ 复用推挽输出（AF_PP）

| 模式 | 宏 | 值 | 谁控制引脚 |
|---|---|---|---|
| **普通推挽** | `GPIO_CFG_OUT_PP_50MHZ` | `0x3` | **你写 `ODR`/`BSRR`** |
| **复用推挽** | `GPIO_CFG_AF_PP_50MHZ` | `0xB` | **定时器等外设**，`ODR` 无效 |

**用错会怎样**：

```c
gpio_config(GPIOA, 0, GPIO_CFG_OUT_PP_50MHZ);   /* ❌ 普通推挽 */
TIM2->CCR1 = 50;                                /* 定时器在算，但引脚不听 */
/* 结果：引脚一直是上次 BSRR 写的电平，PWM 完全没输出 */
```

**"复用"的字面意思就是"把引脚交给外设管"。**

### 5.4 呼吸灯完整代码

```c
#include "stm32f103.h"
#include "led.h"
#include "Delay.h"

#define LED_PIN  0        /* PA0 = TIM2_CH1 */

int main(void)
{
    /* 1. 时钟 */
    RCC->APB1ENR |= RCC_APB2ENR_TIM2EN;
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;

    /* 2. PA0 配为复用推挽 */
    gpio_config(GPIOA, LED_PIN, GPIO_CFG_AF_PP_50MHZ);

    /* 3. 时基：10 kHz */
    TIM2->PSC = 71;          /* 72MHz / 72  = 1 MHz */
    TIM2->ARR = 99;          /* 1MHz  / 100 = 10 kHz */
    TIM2->CNT = 0;

    /* 4. CH1 PWM 模式 1 + 预装载 */
    TIM2->CCMR1 = (6UL << 4) | (1UL << 3);    /* OC1M=110, OC1PE=1 */

    /* 5. 使能 CH1 输出（高电平有效）*/
    TIM2->CCER |= 1;                          /* CC1E=1, CC1P=0 */

    /* 6. 载入 + 清标志 */
    TIM2->EGR = 1;
    TIM2->SR  = (uint16_t)~1;

    /* 7. 启动（ARR 预装载 + 使能）*/
    TIM2->CR1 |= (1UL << 7) | 1;              /* ARPE=1, CEN=1 */

    uint32_t duty = 0;

    while (1)
    {
        for (duty = 0; duty <= 99; duty++)     /* 渐亮 */
        {
            TIM2->CCR1 = duty;
            Delay_ms(10);
        }
        for (duty = 0; duty <= 99; duty++)     /* 渐暗 */
        {
            TIM2->CCR1 = 99 - duty;
            Delay_ms(10);
        }
    }
}
```

**实测效果**：LED 由暗到亮再到暗，**一轮约 2 秒**（100 步 × 10ms × 2 个方向）。

### 5.5 `OC1PE = 1`（预装载）为什么重要

| 设置 | 改 `CCR1` 时 |
|---|---|
| **OC1PE = 1** | 写在预装载寄存器，**下个更新事件才生效** → 无毛刺 |
| **OC1PE = 0** | **立即生效** → 如果在 CNT 数到中途把 CCR 改小，可能出现异常窄脉冲 / 宽脉冲 |

**呼吸灯每 10ms 改一次占空比，如果关掉预装载，波形会有毛刺**（肉眼可能看不出，但逻辑分析仪能抓到）。

### 5.6 硬件接线

```
PA0 ──[ 220Ω ~ 1kΩ ]── LED 长脚(+) ── LED 短脚(-) ── GND
```

**⚠️ 注意**：

| 项 | 说明 |
|---|---|
| **极性** | PA0 输出**高电平时点亮**（占空比越大越亮）；接反了完全不亮 |
| **限流电阻必须有** | 直接接 3.3V 可能烧 LED 或拉低引脚电平 |
| **板载 LED 用不了** | 板载 LED 在 **PC13**，而 **PC13 没有定时器通道**，只能外接 |

## 七、思考题与答案

### Day 1 的五题

| # | 问题 | 答案 |
|---|---|---|
| **1** | 500 Hz 的 PSC / ARR？ | `(39, 3599)` → 40×3600=144000；或 `(99, 1439)` → 100×1440=144000 |
| **2** | `PSC=7199, ARR=999` 是多少 Hz？ | 72M/7200/1000 = **10 Hz** |
| **3** | 想每 10 μs 加 1，PSC 多少？ | 目标 100 kHz → 72M/100k = 720 → **PSC = 719** |
| **4** | 为什么 APB1 是 36MHz 但 TIM2 是 72MHz？ | APB1 预分频系数 >1 时，定时器时钟自动 **×2**，等于 HCLK |
| **5** | `TIM->SR &= ~1` 和 `EXTI->PR = (1<<5)` 的区别？ | SR 是 **W0C**（写 0 清），PR 是 **W1C**（写 1 清）；两者都**不要用读-改-写** |

### Day 3 的五题

| # | 问题 | 答案 |
|---|---|---|
| **1** | 呼吸周期改 4 秒？ | `Delay_ms(5)` → `Delay_ms(10)` |
| **2** | 20 kHz 的 PSC / ARR？ | `(4, 719)` → 5×720=3600 → 72M/3600 = **20 kHz** |
| **3** | `OC1PE=1` 的好处？ | 改占空比时下个更新事件才生效，**不出毛刺**；关掉则立即生效，可能产生异常窄脉冲 |
| **4** | 为什么低频会闪、高频不闪？ | **视觉暂留 / 临界闪烁融合**：LED 约 60~90 Hz 以上就看不出闪烁，越亮越容易察觉 |
| **5** | 怎样做到 100% 常亮？ | **`CCR1 = ARR + 1`**（本项目写 100），`CNT < CCR` 永远成立 → 一直高电平 |

**⚠️ 第 5 题一开始答错了**（以为 PWM 模式 1 做不到 100%），实际是可以的。

## 八、踩坑记录

| # | 坑 | 现象 | 原因 |
|---|---|---|---|
| **1** | `main.c` 里 `#include "stm32f10x.h"` | 报 `NVIC_IPR` / `IRQ_TIM2` / `NVIC_ISER0` undefined | 那是 SPL 的头文件，**没有你自定义的宏**；应 include `stm32f103.h` |
| **2** | 忘了 `LED_Init()` | 定时器正常但 LED 不亮 | PA12 还是默认浮空输入 |
| **3** | 忘了 `EGR = 1` | 频率不对（配置不生效） | PSC/ARR 没载入影子寄存器 |
| **4** | 忘清 `SR` | 一开中断就闪一下 | `UG` 顺带把 `UIF` 置 1 |
| **5** | 用了普通推挽 | PWM 完全无输出 | 引脚不受定时器控制，必须 `AF_PP`（0xB） |
| **6** | 忘了 `CCER` 的 `CC1E` | 定时器在算但不输出 | 输出没使能 |

## 九、结论

1. **时基公式**：`f = f_clk / ((PSC+1)(ARR+1))`，**两个都 +1**。
2. **APB1 上的定时器时钟是 APB1 频率的 2 倍**（分频系数 >1 时）。
3. **`EGR = 1` 用来载入影子寄存器**，之后必须清 `SR`（`UG` 会置 `UIF`）。
4. **清标志一律用直接赋值**：`SR = ~mask`（W0C）、`PR = mask`（W1C）。
5. **PWM 必须用复用推挽 `0xB`**，普通推挽引脚不受定时器控制。
6. **PWM 模式 1 支持 0%~100%**：`CCR=0` 全灭、`CCR=ARR+1` 全亮。
7. **`OC1PE=1` 让占空比改动在周期边界生效**，避免毛刺。
