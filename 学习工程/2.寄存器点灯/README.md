# 2.寄存器点灯 —— 手写寄存器 GPIO

> W7 学习工程：不调用任何库函数，直接操作 STM32F103 寄存器实现 LED 与按键。

## 一、功能
- 按键按一下，LED 翻转一次

## 二、硬件连接
| 功能 | 引脚 | 说明 |
|---|---|---|
| LED | PA12 | 低电平点亮 |
| 按键 | PA5  | 上拉输入，按下接地（读到 0） |

## 三、时钟配置
| 项 | 值 | 说明 |
|---|---|---|
| HSE | 8 MHz | 外部晶振 |
| PLL | ×9 | SystemInit() 配置 |
| SYSCLK | 72 MHz | HCLK = AHB ÷1 |
| APB2 | 72 MHz | GPIO 挂在这条总线 |
| 已使能 | IOPAEN (bit2) | RCC->APB2ENR |

## 四、用到的寄存器
| 寄存器 | 地址 | 作用 |
|---|---|---|
| RCC->APB2ENR | 0x40021018 | 使能 GPIOA 时钟（bit2 = IOPAEN） |
| GPIOA->CRL | 0x40010800 | 配置 PA0~PA7（本工程：PA5 上拉输入） |
| GPIOA->CRH | 0x40010804 | 配置 PA8~PA15（本工程：PA12 推挽输出） |
| GPIOA->BSRR | 0x40010810 | 原子置位/复位（LED 亮灭） |
| GPIOA->IDR | 0x40010808 | 读输入电平（按键） |

## 六、关键实现说明
6.1 为什么用 BSRR 而不是 ODR
`GPIOA->ODR |= (1<<pin)` 是读-改-写三步操作。如果中途被中断打断，
中断里改了同一端口的其他位，写回时会把中断的改动覆盖掉（竞态）。
`GPIOA->BSRR = (1<<pin)` 是单次写、原子操作：
低 16 位写 1 置位，高 16 位写 1 复位，写 0 无影响。

6.2 CRL/CRH 的分支
每个引脚占 4 位配置位：
- `pin < 8`  → `CRL`，位置 `pin * 4`
- `pin >= 8` → `CRH`，位置 `(pin - 8) * 4`
统一封装在 `gpio_config()` 里，所以上层改引脚（哪怕是 CRL↔CRH 跨组）都不用改代码。

6.3 按键消抖三步
1. 延时等待：`Delay_ms(20)` 等触点弹跳结束
2. 二次确认：再读一次，仍为按下才算数（排除毛刺）
3. 等松手：`while(按下){}`，避免按住不放被反复触发
缺第 3 步的话，按住 1 秒 LED 会翻转几十次。
